I'm Umid Norbekov, known online as Zerosec: a penetration tester and security researcher based in Ontario, Canada. I work on web application security, the security of AI and LLM applications, and OSINT.

I came to hands-on security from the classroom. For almost ten years I taught information security theory and geopolitics at university level. That shapes how I work: I don't look at a vulnerability in isolation, but at what it means for the organisation, its operations and, sometimes, the wider security picture. I try to write findings that the people who have to decide on a fix can actually act on.

## What I do

- **Bug bounty.** Security researcher on HackerOne since December 2025. I also report to other programs, including [Yandex](../writeups/yandex-alice-safety-filter-bypass/).
- **AI security.** I test LLM applications for prompt injection and safety filter bypasses, and I build the open-source [Prompt Injection Lab](https://github.com/umid1988/AI-Security-Prompt-Injection-Lab) so others can learn these attacks hands-on.
- **Penetration testing.** Web exploitation (SQL injection, command injection, XSS, file upload flaws, authentication bypass), privilege escalation on Linux and Windows, Active Directory attack chains and post-exploitation, practised in labs and a homelab built on Hyper-V, Kali Linux and OpenVPN.
- **Threat research and writing.** Articles on AI-enabled threats such as [APT28's LameHug](../notes/apt28-lamehug-llm-malware/), tool poisoning and guardrail-bypassing malware, in English and Uzbek.
